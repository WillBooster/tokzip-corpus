>
```

应该写成行内表达式：

``` html
<button v-bind:class="'btn btn-' + size"></button>
```

或者计算属性：

``` html
<button v-bind:class="buttonClasses"></button>
```

``` js
computed: {
  buttonClasses: function () {
    return 'btn btn-' + size
  }
}
```
