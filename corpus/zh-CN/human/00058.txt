## 带字符串 property 路径的 `store.watch` <sup>替换</sup>

`store.watch` 现在只接受函数。因此，下面例子你需要替换：

``` js
store.watch('user.notifications', callback)
```

为：

``` js
store.watch(
  // 当返回结果改变...
  function (state) {
    return state.user.notifications
  },
  // 执行回调函数
  callback
)
```

这帮助你更加完善的控制那些需要监听的响应式 property。
