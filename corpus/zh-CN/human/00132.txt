不再会有一个特殊的 API 用来初始化包含 Vue Router 的 app，这意味着不再是：

``` js
router.start({
  template: '<router-view></router-view>'
}, '#app')
```

你只需要传一个路由 property 给 Vue 实例：

``` js
new Vue({
  el: '#app',
  router: router,
  template: '<router-view></router-view>'
})
```

或者，如果你使用的是运行时构建 (runtime-only) 方式：

``` js
new Vue({
  el: '#app',
  router: router,
  render: h => h('router-view')
})
```
