</div>

在方法中，我們可以使用 `this` 來訪問組件實例。組件實例會暴露 `data` 中聲明的數據屬性。我們可以通過改變這些屬性的值來更新組件狀態。

</div>

  // 更新組件狀態

}

此處，`increment` 引用了一個從 `setup()` 對象返回的方法：

```js{$}
setup() {
  const count = ref(0)

  function increment(e) {
    // 更新組件狀態
    count.value++
  }

  return {
    count,
    increment
  }
}
```
