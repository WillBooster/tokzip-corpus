# 事件監聽 {#event-listeners}

我們可以使用 `v-on` 指令監聽 DOM 事件：

```vue-html
<button v-on:click="increment">{{ count }}</button>
```

因為其經常使用，`v-on` 也有一個簡寫語法：

```vue-html
<button @click="increment">{{ count }}</button>
```

<div class="options-api">

此處，`increment` 引用了一個使用 `methods` 選項聲明的函數：

<div class="sfc">

```js{7-12}
export default {
  data() {
    return {
      count: 0
    }
  },
  methods: {
    increment() {
      // 更新組件狀態
      this.count++
    }
  }
}
```

</div>
<div class="html">

```js{7-12}
createApp({
```
