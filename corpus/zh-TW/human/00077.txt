# 狀態管理 {#state-management}

## 什麼是狀態管理？ {#what-is-state-management}

理論上來說，每一個 Vue 組件實例都已經在“管理”它自己的響應式狀態了。我們以一個簡單的計數器組件為例：

<div class="composition-api">

```vue
<script setup>
import { ref } from 'vue'

// 狀態
const count = ref(0)

// 動作
function increment() {
  count.value++
}
</script>

<!-- 視圖 -->
<template>{{ count }}</template>
```

</div>
<div class="options-api">

```vue
<script>
export default {
  // 狀態
  data() {
    return {
      count: 0
    }
  },
  // 動作
  methods: {
    increment() {
      this.count++
    }
  }
}
</script>
