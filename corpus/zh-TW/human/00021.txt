## 為組件的 props 標註類型 {#typing-component-props}

### 使用 `<script setup>` {#using-script-setup}

當使用 `<script setup>` 時，`defineProps()` 宏函數支持從它的參數中推導類型：

```vue
<script setup lang="ts">
const props = defineProps({
  foo: { type: String, required: true },
  bar: Number
})
