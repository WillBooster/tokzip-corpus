## PropType\<T> {#proptype-t}

用於在用運行時 props 聲明時給一個 prop 標註更復雜的類型定義。

- **示例**

  ```ts
  import type { PropType } from 'vue'

  interface Book {
    title: string
    author: string
    year: number
  }

  export default {
    props: {
      book: {
        // 提供一個比 `Object` 更具體的類型
        type: Object as PropType<Book>,
        required: true
      }
    }
  }
  ```
