## 聲明響應式狀態 \* {#declaring-reactive-state}

選用選項式 API 時，會用 `data` 選項來聲明組件的響應式狀態。此選項的值應為返回一個對象的函數。Vue 將在創建新組件實例的時候調用此函數，並將函數返回的對象用響應式系統進行包裝。此對象的所有頂層屬性都會被代理到組件實例 (即方法和生命週期鉤子中的 `this`) 上。

```js{2-6}
export default {
  data() {
    return {
      count: 1
    }
  },
