# アセット

## directives

- **型:** `Object`

- **詳細:**

  コンポーネントインスタンスで利用可能なディレクティブのハッシュです。

- **使用方法:**

  ```js
  const app = createApp({})

  app.component('focused-input', {
    directives: {
      focus: {
        mounted(el) {
          el.focus()
        }
      }
    },
    template: `<input v-focus>`
  })
  ```
