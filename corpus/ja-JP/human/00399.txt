## components

- **型:** `Object`

- **詳細:**

  コンポーネントインスタンスで利用可能なコンポーネントのハッシュです

- **使用方法:**

  ```js
  const Foo = {
    template: `<div>Foo</div>`
  }

  const app = createApp({
    components: {
      Foo
    },
    template: `<Foo />`
  })
  ```

- **参照:** [コンポーネント](../guide/component-basics.html)
