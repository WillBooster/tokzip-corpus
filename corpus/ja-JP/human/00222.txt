## PropType\<T> {#proptype-t}

ランタイム props 宣言を使用する際、より具体的な型で props に注釈を付けるために使われます。

- **例**

  ```ts
  import type { PropType } from 'vue'

  interface Book {
    title: string
    author: string
    year: number
  }

  export default {
    props: {
      book: {
        // より具体的な型を `Object` に提供します
        type: Object as PropType<Book>,
        required: true
      }
    }
  }
  ```
