## 引数

`setup` 関数を使う時、2 つの引数を取ります:

1. `props`
2. `context`

それぞれの引数がどのように使われるのか、深く掘り下げてみましょう。

### プロパティ

`setup` 関数の第 1 引数は `props` 引数です。標準コンポーネントで期待するように、`setup` 関数内の `props` はリアクティブで、新しい props が渡されたら更新されます。

```js
// MyBook.vue

export default {
  props: {
    title: String
  },
  setup(props) {
    console.log(props.title)
  }
}
```
