もしこのコンポーネントが `id` 属性と `v-on:close` リスナを受け取った場合、 `$attrs` オブジェクトは次のようになります:

```js
{
  id: 'my-input',
  onClose: () => console.log('close Event triggered')
}
```

## 移行の戦略

`$listeners` の使用をすべて削除します。

[移行ビルドのフラグ: `INSTANCE_LISTENERS`](migration-build.html#compat-の設定)
