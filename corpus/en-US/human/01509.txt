## Quickstart

Firstly, let's create a file `url_bench.ts` and register a bench using the
[`Deno.bench()`](/api/deno/~/Deno.bench) function.

```ts
// url_bench.ts
Deno.bench("URL parsing", () => {
  new URL("https://deno.land");
});
```
