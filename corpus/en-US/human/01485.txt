## `deno uninstall [PACKAGES]`

Remove dependencies specified in
[`deno.json`](/runtime/fundamentals/configuration/) or `package.json`:

```sh
deno add npm:express
Add npm:express@5.0.0

cat deno.json
{
  "imports": {
    "express": "npm:express@5.0.0"
  }
}
```
