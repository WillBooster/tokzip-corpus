This rule is especially useful in libraries where you almost never want to
output to the console.

**Invalid:**

```typescript
console.log("Debug message");
console.error("Debug message");
console.debug(obj);

if (debug) console.log("Debugging");

function log() {
  console.log("Log");
}
```
