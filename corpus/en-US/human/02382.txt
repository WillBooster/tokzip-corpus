| Node.js tooling    | Deno         |
| ------------------ | ------------ |
| `npm install`      | deno install |
| `npm run <script>` | deno task    |
| `eslint`           | deno lint    |
| `prettier`         | deno fmt     |
| `jest` / `mocha`   | deno test    |
| `tsc --noEmit`     | deno check   |
