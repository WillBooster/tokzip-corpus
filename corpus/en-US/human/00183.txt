# Emits {#emits}

In addition to receiving props, a child component can also emit events to the parent:

<div class="composition-api">
<div class="sfc">

```vue
<script setup>
// declare emitted events
const emit = defineEmits(['response'])

// emit with argument
emit('response', 'hello from child')
</script>
```

</div>

<div class="html">

```js
export default {
  // declare emitted events
  emits: ['response'],
  setup(props, { emit }) {
    // emit with argument
    emit('response', 'hello from child')
  }
}
```
