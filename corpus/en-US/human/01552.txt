`deno clean` removes Deno's global module cache directory. See
[Modules](/runtime/fundamentals/modules/) for more information about how Deno
caches dependencies.

## Basic usage

```sh
deno clean
```

## Dry run

Preview what would be deleted without actually removing anything:

```sh
deno clean --dry-run
```
